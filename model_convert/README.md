# CuteTTS-distill → AX650 转换流程

本目录包含完整的可复现转换脚本（从 HuggingFace 权重到 axmodel）。

## 0. 准备

```bash
pip install torch transformers safetensors sentencepiece soundfile scipy onnx onnxruntime
# Pulsar2 8.0 (https://pulsar2-docs.readthedocs.io)，默认路径 /root/.cache/magnetar/pulsar2/8.0
```

把上游 `OPPOer/CuteTTS-distill` 放到 `origin/`，结构：

```
origin/
  config.json
  tokenizer/{tokenizer.model, tokenizer_config.json, added_tokens.json, ...}
  weights/tts/model.safetensors
  weights/audio_vae/{config.json, model.safetensors}
  weights/speaker_encoder/{config.json, model.safetensors}
```

以及 CuteTTS 官方推理代码（`cutetts` 包）放在 `../CuteTTS/src`，脚本通过
`CUTETTS_SRC` 环境变量定位（默认 `/ai_data/AX615/hy/workspace/TTS_Train/TTS_quant/CuteTTS/src`）。

## 1. 导出 ONNX

```bash
python export_onnx.py        # vae_enc / speaker_enc / locenc_step / lm_prefill / lm_decode / vae_dec_l{64,128,256}
python export_dit1.py        # 单步 AudioDiT（host 循环 4 步）
python export_assets.py      # embed_tokens.npy / lm_speaker_proj.npy / mel_filter.npy / config.json
```

每个图都会用 onnxruntime 与 PyTorch 逐张量对比（cosine 打印在终端，全部 ≥0.999999）。
LM 额外与 HuggingFace `Qwen3Model` 原实现对比（prefill/decode 均 1.0）。

## 2. 校准集

```bash
python make_calib.py         # 真实语音 → VAE latent / log-mel / 真实 prompt / 真实 KV / 扩散步输入
python make_calib_dit1.py    # 单步扩散头的 t=0/0.25/0.5/0.75 四组
```

校准数据来自 14 条真实语音（中英文、6–48 kHz），包括真实的 LM KV cache 和
扩散步中间量，而不是随机噪声。

## 3. 编译

```bash
python prepare_compile.py                 # 只生成 config
python prepare_compile.py --run           # 调用 pulsar2 build
# 或单个：python prepare_compile.py --models lm_decode --run
```

配置要点：

- `target_hardware=AX650`，`npu_mode`：卷积类 NPU3，Transformer/LM NPU1
- `layer_configs`: 所有 op U16（激活/权重/输出），`highest_mix_precision=false`
- `compiler.check=0`（不做仿真，全部上板验证）

产物在 `compile/*.axmodel`，日志在 `compile/logs/`。

## 4. 精度/性能验证

```bash
# 板端（AX650，pyaxengine）
python python/demo.py --model-dir models --assets models/assets \
  --text "The voice generated by this model sounds amazing!" \
  --reference samples/reference.wav --output out.wav
```

`demo.py` 会打印各阶段耗时；`sdk/transcribe.py`（可选）用 SenseVoice 做 ASR 校验。
