# CuteTTS.AXERA

**AX650 上的 0.2B 连续隐变量自回归 TTS：zero-shot 音色克隆 · 24 kHz · 9 个 axmodel 全 NPU 推理**

> **真流式（音频级，非切句）**：AR 循环不停，VAE 用 80-latent 精确滑动窗（64 上下文 + 16 新 latent）
> 解码，**每 1.28 s 输出一包、流式输出与离线逐样本一致**（SNR 151~154 dB）；
> TTFT 1.1~1.2 s（缓存参考音色后 0.46 s）。同时保留非流式整句模式。

## 快速开始（AX650 板端）

从 HuggingFace 下载 `models/`、`bin/`、`python/`、`samples/` 到包根目录：

```bash
bash setup.sh

# C++（默认，最快）
bash run_ax650.sh "The voice generated by this model sounds amazing!" samples/reference.wav out.wav

# 真流式（每 160 ms 一包，首包 ≈0.7 s）
bash run_ax650.sh "The voice generated by this model sounds amazing!" samples/reference.wav out.wav --stream

# Python SDK（流式 / 非流式）
bash run_ax650.sh "今天天气很好，我们一起去公园散步吧。" samples/reference.wav zh.wav --python --stream

# 调 CFG / 随机种子 / 最长 patch 数（1 patch ≈ 160 ms）
bash run_ax650.sh "Hello from AX650!" samples/reference.wav en.wav --cfg 2.0 --seed 42 --max-new 128
```

Python SDK：

```python
import sys; sys.path.insert(0, "python")
from cutetts_ax import CuteTTSAX
import cutetts_ax.audio as A

tts = CuteTTSAX("models", "models/assets")
wav = tts.synthesize("The voice generated by this model sounds amazing!", "samples/reference.wav")
A.write_wav("out.wav", wav, tts.sr)
print(tts.last_timing)
```

参考音频 ≤ 5 s；单次生成 ≤ 20.5 s；输出 24 kHz 单声道。

## 推理速度

| 模式 | 实现 | 音频 | TTFT | 总耗时 | RTF | 出包间隔 |
|---|---|---|---|---|---|---|
| **流式（精确）** | C++ | 3.04 s | **0.48~0.54 s**（首次 1.08 s） | 1.86~1.91 s | 0.61~0.63 | 1.28 s |
| **流式（精确）** | Python | 2.88 s | **0.58~0.61 s**（首次 1.13 s） | 1.68~1.70 s | 0.58~0.59 | 1.28 s |
| 非流式 | C++ | 3.04 s | 1.48 s | 1.48 s | **0.49** | — |
| 非流式 | Python | 2.88 s | 1.61 s | 1.61 s | 0.56 | — |

- 10.2 s 长句：流式 C++ `TTFT 0.56 s / RTF 0.49`；短句 RTF 偏高是参考编码（0.41 s）等固定开销摊薄不了
- **参考音色缓存**（C++ 写 `cache/ref/*.ref`，Python 写 `cache/ref/*.npz`，跨进程复用）：
  同一参考音频再次合成时跳过 `vae_enc`（0.30 s）与音色编码（0.11 s），TTFT 从 ~1.1 s 降到 ~0.5 s
- 流式输出与离线**逐样本一致**（cos 1.000000）

**指标定义**

- **RTF（Real-Time Factor）= 总耗时 / 音频时长**，越小越好；`RTF < 1` 表示合成快于实时。
- **TTFT（Time To First Token，首包时延）= 发起请求到拿到第一段音频的时间**：
  流式下 = 参考特征提取（缓存命中则跳过）+ 首包 4 个 latent 的 AR + 一次窗口解码；
  非流式下 = 整句端到端耗时。启动时的模型预热不计入 TTFT。

**流式实现（真流式，不是切句）**

- AR 循环只跑一次、latent 连续产生；每攒够 16 个 latent（1.28 s）用 `vae_dec_l80`
  解码一次：窗口 `[t-80, t)`（前 64 个 latent 作因果上下文，只输出新增 16 个）。
- 解码器实测感受野 60 latent，窗口上下文 ≥64 即与整句离线解码**逐样本一致**。
- 首包只等 4 个 latent（0.32 s）以加快首响；`--first-chunk/--chunk` 可调。

## 目录结构

```text
CuteTTS.AXERA/
├── cpp/                     # C++ 源码（AX_ENGINE）与交叉编译脚本
├── model_convert/           # ONNX 导出 / 校准 / Pulsar2 编译脚本
├── docs/implementation.md   # 子图拆分、KV cache、静态 shape、量化细节
├── python/                  # numpy-only SDK + demo
├── models/                  # 从 HuggingFace 下载的 9 个 axmodel
├── samples/                 # 参考音色 + 板端样例
└── run_ax650.sh             # 一键脚本（默认 C++，--python 切 SDK）
```

## 模型转换

```bash
python model_convert/export_onnx.py      # 7 个子图，逐张量 cosine 校验
python model_convert/export_dit1.py      # 单步扩散头
python model_convert/export_spk_body.py  # ECAPA 主干
python model_convert/export_assets.py    # embedding 表 / tokenizer / C++ 资产
python model_convert/make_calib.py       # 真实语音校准集（含真实 KV cache、首 patch）
python model_convert/prepare_compile.py --run
```

需要准备上游 `OPPOer/CuteTTS-distill` 权重与 CuteTTS 官方推理代码（`CUTETTS_SRC` 环境变量）。
